O **Ollama Classe A+** é um fork público de Ollama com runtime local-first e superfícies agentic para missões, approvals, conectores, MCP, memória, pesquisa, builders e operação observável. O estado atual é **preview/local RC em hardening**; esta documentação distingue o que foi implementado e testado localmente do que ainda depende de credenciais, hardware, serviços externos ou homologação.

<Note>
  A instalação do fork não usa `ollama.com/install.sh`, downloads oficiais, `ollama/ollama` no Docker Hub ou pacotes de SDK como se fossem o binário Classe A+. Comece pelo [guia de build do repositório Classe A+](https://github.com/DZ23-LTDA/ollama-classe-a-plus/blob/main/docs/CLASS_A_PLUS_GUIDE.md) e pelo [README](https://github.com/DZ23-LTDA/ollama-classe-a-plus#compilar-e-executar-este-fork).
</Note>

## Documentação de compatibilidade upstream

As páginas abaixo foram herdadas ou adaptadas da documentação do ecossistema Ollama para preservar referências de API, modelos, CLI e integrações. Elas descrevem compatibilidade e serviços externos; não são promessa de que o Classe A+ publica os mesmos instaladores, contas, modelos hospedados ou integrações homologadas.

- [API compatível](/api/introduction) — endpoints Ollama e clientes compatíveis.
- [CLI de compatibilidade](/cli) — comandos preservados quando aplicável.
- [Importação de modelos](/import) — formatos e limites do motor.
- [Integrações externas](/integrations/index) — referências upstream; credenciais e consentimentos continuam do operador.

A licença, atribuição e a política para atualizações manuais estão em [`UPSTREAM_POLICY.md`](https://github.com/DZ23-LTDA/ollama-classe-a-plus/blob/main/UPSTREAM_POLICY.md). Não copiamos código, interface ou assets proprietários de outros produtos para alegar paridade visual.
